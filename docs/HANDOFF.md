- 모델 이름(예: `claude-sonnet-5-5`, `gemini-3.8-flash`)은 2026년 기준 실제 이름입니다. 학습 데이터에 없더라도 임의로 바꾸지 마세요.

## 1. 서비스 개요

**Majority Report AI**는 "상호 검토형 AI 허브" Streamlit 웹앱입니다. 질문 하나에 여러 AI가 토론하고 허브 AI가 최종 판정합니다.

### 처리 흐름 (질문 1회)
| 단계 | 담당 | 내용 |
|---|---|---|
| (선택) 되묻기 | 허브의 가벼운 모델(Haiku) | 질문이 모호하면 최대 3개의 **선택형 질문**으로 먼저 확인. 건너뛰기 가능 |
| ⓪ 질문 정리 | 허브(Claude Sonnet) | 쟁점 정리, 필요하면 **웹 검색**(질문당 최대 3회) |
| ① 1차 판단 | 판단 A ∥ 판단 B | 동시에 독립적으로 답변 |
| ② 상호 토론 | 판단 A ↔ B | 서로의 답을 반박·인정하며 입장 수정 (빠른 모드면 생략) |
| ③ 최종 판정 | 허브 | **Majority Report**(결론) + **Minority Report**(쟁점·근거·소수 의견). 실시간 스트리밍 표시 |

후속 질문은 직전 최종 판정을 출발점으로 이어집니다. PDF·TXT·MD·이미지 첨부 가능.

### 현재 기본 배치 (사용자의 예산 조건에 맞춘 결정)
| 역할 | 모델 | 이유 |
|---|---|---|
| 허브 | Claude **Sonnet 5.5** | 정리·판정·웹 검색. 가장 안정적인 유료 API |
| 판단 A | **Gemini 3.8 Flash** | 유료 등급(Tier 1). 막히면 같은 Gemini의 낮은 모델 → 다른 AI 순으로 자동 교체 |
| 판단 B | **자동 선택**(기본 켜짐, `AUTO_JUDGE_B`) | 입력 5,000자 이하·이미지 없음 → **Groq → Mistral → Haiku 5.5**. 긴 입력·이미지 → **Haiku 5.5 우선**. 끄면 직접 선택 |

## 2. 계정·결제 현황 (사용자 환경)

| 서비스 | 상태 | 비고 |
|---|---|---|
| **Claude API** | Team 계정으로 **매달 약 150달러** API 사용 가능 | 앱 사이드바에 월 누적 추정액 / 예산 막대 표시 |
| **Gemini API** | **유료 Tier 1** | Google AI Pro 구독 혜택으로 **매달 약 10달러 Google Cloud 크레딧**(Google Developer Program) 수령. 앱 사이드바에 Gemini 월 예산 $10 막대 표시 |
| Groq, Mistral 등 | 무료 등급 | 대타(교체용) |
| ChatGPT | Team 구독 사용 중 | **ChatGPT 구독에는 API가 포함되지 않음** (API는 platform.openai.com에서 별도 결제) |
| Perplexity | Pro 구독 | Pro의 월 API 크레딧 혜택은 2026년 2월 종료된 것으로 보임 (미확인) |

### Gemini 결제 설정에서 있었던 일 (재발 시 참고)
1. Google Cloud에 결제 계정이 둘 있었음("내 결제 계정", "My Billing Account"). 크레딧은 **"내 결제 계정"**에 들어옴.
2. API 키 프로젝트를 "내 결제 계정"으로 옮겼더니 무료 체험 계정이라 **무료 등급으로 내려감** → "결제 활성화"(정식 계정 전환)로 **Tier 1** 복귀.
3. 그 뒤 Gemini가 모든 모델에서 "사용량 한도 초과"로 보였는데, 원인은 **AI Studio 선불 크레딧 잔액이 ₩0**이었기 때문. AI Studio 결제 화면에 "서비스를 재개하려면 크레딧 잔액이 $0보다 커야 합니다"라는 안내가 있었음. 해결: **크레딧 구매하기**로 최소 금액 충전(월 GCP 크레딧이 먼저 차감됨).
4. 무료 체험 크레딧(약 30만 원)은 Gemini API에는 적용되지 않는 것으로 보임.
5. 쓰지 않는 결제 계정 정리, 해지된 카드 삭제(다른 Google 서비스의 기본 결제수단이면 먼저 변경 필요)까지 진행.

**사용자에게 권장한 것:** Cloud 결제 계정에 월 ₩15,000 정도 **예산 알림**, AI Studio **자동 충전은 꺼 두기**.

## 4. 핵심 동작 규칙

### 한도 초과·오류 시 판단자 교체 순서
1. **같은 AI의 낮은 모델** (예: `gemini-3.8-flash` → flash-lite 계열, Groq `gpt-oss-120b` → `gpt-oss-20b`)
2. **다른 AI** (Groq, Mistral, OpenRouter)
3. **허브 AI의 다른 모델** (Sonnet 허브 → Haiku)
4. **허브가 같은 모델로 겸함** (최후의 수단)
5. 그래도 둘 다 실패하면 **허브가 단독으로 답하고** "상호 검토가 빠진 답"이라고 알림

- 자동 제외는 **모델 단위**이고 앱 서버 메모리에 저장되어 새로고침해도 유지됩니다. 사이드바에 "⏸ 자동 제외 중"과 **제외 해제** 버튼이 있습니다.
- 제외 시간: Gemini 일일 한도는 태평양 자정까지, 분당 한도는 API가 알려준 대기 시간(최소 1분), 모르면 10분.
- 모델 목록 조회가 실패하면 이름 추정과 Google 고정 별칭(`gemini-flash-lite-latest`, `gemini-flash-latest`)을 씁니다. 404로 확인된 모델은 24시간 동안 다시 부르지 않습니다.
- 판단 시간 제한(기본 90초)은 재시도와 교체를 포함한 **단계 전체 상한**입니다.

### 판단 B 자동 선택 (PR #15)
- 판단 B만 입력에 따라 고릅니다. 허브와 판단 A는 그대로입니다.
- **전체 입력**(질문·첨부 문서·이전 대화·되묻기 답·형식 문구 포함)이 5,000자 이하이고 이미지가 없으면 Groq → Mistral → Haiku 5.5, 넘거나 이미지가 있으면 Haiku 5.5 우선입니다. 이전에 첨부한 자료도 같은 대화 안에서는 계속 기준에 들어갑니다.
- 무료 후보는 호출당 최대 7.5초, 질문 전체 최대 15초만 기다리고, 실패하면 바로 다음 후보로 갑니다. Haiku로 바뀌면 반론도 Haiku로 진행하고, Haiku도 실패하면 Claude 기본 모델을 마지막으로 시도합니다.
- 진행판과 저장 기록에 선택 이유가 남습니다. 예: `🧭 판단 B 자동 선택 · 이미지 포함 · Claude Haiku 5.5 → Claude Sonnet 5.5`. 오류가 아니라 안내입니다.

### 비용 계산 (PR #5, #14)
- **Claude와 Gemini** 응답의 실제 사용량(입력·출력·생각·캐시 토큰)과 Claude 웹 검색 횟수로 계산합니다.
- 요금(100만 토큰당): Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50(10만 토큰 초과 입력은 더 비쌈), Claude 검색 1회 $0.01. Gemini 3.8 Flash는 2026년 할인가 $0.75/$3.75, 2027년부터 $1.50/$7.50으로 구분합니다.
- 진행판에서 호출이 끝날 때마다 공급자별 비용이 갱신되고, 답변 아래에 질문 전체 비용, 사이드바에 Claude·Gemini 각각의 이번 달 누적액과 예산이 표시됩니다.
- 이 값은 대화 기록 기준 추정치입니다. 크레딧, 세금, Gemini 검색 요금·무료 허용량, 앱 밖 사용, 중단·삭제한 대화는 빠집니다.
- **실측(2026-11-08 오후, 최근 7개 질문):** 소요 시간 **38~89초**(대부분 40~60초), 질문당 Claude **약 $0.06~0.16**, Gemini **약 $0.01**, 교체 경고 없음.

### 첨부·알림·평가 (PR #17, #18)
- **이미지는 첨부한 질문에만** 보냅니다. 사이드바 **📎 첨부 관리**에서 "이전 이미지도 계속 보내기"를 켜거나 **첨부 해제**로 쌓인 문서·이미지를 지울 수 있습니다. 문서는 이어지는 질문에서도 계속 참고합니다.
- 알림 중 🧭(판단 B 선택)·🔎(검색)·💰(비용) 안내는 회색 글씨, 그 밖의 경고(⚠️ ⌛ ✂️)는 노란 상자로 표시합니다.
- 답변마다 **👍/👎 평가**가 있고, 대화 기록의 각 질문에 `rating: "up" | "down"`으로 저장됩니다. 설정 변경(생각 수준, 판단 B 자동 선택 등)의 효과를 비교할 때 근거로 씁니다.

### 기타
- 웹 검색 도구 `web_search_20260318`은 공식 문서로 확인한 최신 버전입니다. 코드는 `allowed_callers: ["direct"]`로 **동적 필터링을 끈 상태**입니다(속도 우선, 미검토 과제).
- 최대 출력: 16,000토큰(스트리밍 판정 32,000). 잘리면 "✂️ 잘렸을 수 있습니다" 알림이 뜹니다.
- 저장은 **백그라운드 단일 작업자**가 처리하고, 실패하면 다음 화면 사이드바에 경고가 뜹니다. 로컬 저장은 원자적 쓰기입니다.
- **중단:** 진행판 위 **⏹ 중단** 버튼을 누르거나 고친 질문을 바로 보내면, 진행 중인 AI 호출이 1초 안에 취소됩니다. 화면 오른쪽 위 Streamlit Stop도 호출은 멈추지만 진행판이 멈춘 채 남습니다.

## 7. 자주 묻는 상황별 대응

| 증상 | 확인할 것 |
|---|---|
| Gemini가 모든 모델에서 "사용량 한도 초과" | AI Studio 결제의 **선불 크레딧 잔액**(0이면 충전), 키가 Tier 1인지, Secrets의 키가 맞는지, 사이드바 **제외 해제** |
| 앱이 안 열리고 비밀번호 안내가 뜸 | Secrets에 `APP_PASSWORD` 추가 |
| Secrets의 모델 설정을 바꿨는데 그대로임 | Streamlit Cloud **Reboot app** |
| 대화 기록 저장 실패 경고 | `GITHUB_TOKEN`의 권한(데이터 저장소 Contents 읽기·쓰기)과 만료 여부 |
| 답이 엉뚱한 질문으로 진행 중 | ⏹ 중단, 또는 고친 질문 바로 보내기 |
| 비용이 예상보다 큼 | `CLAUDE_EFFORT_BRIEF`를 낮추기, 사이드바 누적액과 Console 비교, Gemini 정상 여부(대타로 Claude가 쓰이는지) |
| 짧은 질문인데 판단 B가 Haiku | 이미지가 있거나, 같은 대화의 이전 대화·첨부 문서까지 합쳐 5,000자를 넘은 것. 무료 AI를 쓰려면 새 대화에서 질문 |
| 긴 답변에서 스크롤이 막힘 | Streamlit 버전이 1.65 이상인지 (`requirements.txt`) |
