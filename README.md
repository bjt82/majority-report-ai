# 🔮 Majority Report AI

허브 AI가 질문을 정리하면 두 AI가 토론하고, 허브가 최종 결론을 판정하는 상호 검토형 AI 허브입니다.

## 작동 방식
질문 1회에 API 호출 6회가 일어나며, 허브는 그중 2회만 사용합니다. 되묻기를 켜면 가벼운 확인 호출 1회가 더해집니다.

0. **되묻기**(선택): 허브가 질문을 먼저 살펴, 대상·범위·기간·목적처럼 답이 크게 달라질 모호한 점이 있으면 **선택형 질문**으로 사용자에게 먼저 확인합니다(최대 3개, 복수 선택·직접 입력 가능, 건너뛰기 가능). 물을 것이 없으면 바로 진행하며, 빠르게 끝나도록 허브 쪽 가벼운 모델(예: Haiku)이 판단합니다. 사이드바 **❓ 되묻기**로 끌 수 있습니다.
1. **질문 정리**: 허브 AI(기본 Claude)가 질문·첨부 파일·직전 최종안을 분석해 쟁점을 정리합니다. 최신 정보가 필요하면 허브가 웹 검색으로 확인해 출처와 함께 판단자들에게 넘깁니다.
2. **1차 판단**: 판단 A(기본 Gemini)와 판단 B(기본 Claude Haiku)가 정리된 질문에 독립적으로 동시에 답합니다.
3. **상호 토론**: A는 B의 답을, B는 A의 답을 반박하거나 인정하며 자기 입장을 고칩니다.
4. **최종 판정**: 허브가 토론 전체를 보고 **Majority Report**(최종 결론)와 **Minority Report**(쟁점·판정 근거)를 냅니다.

### 기본 배치
| 역할 | 기본 AI | 이유 |
|---|---|---|
| 허브 | Claude Sonnet | 정리·판정·웹 검색을 맡는 핵심 역할이라 가장 안정적인 유료 API |
| 판단 A | Gemini (무료) | 무료 중 가장 강하고 긴 입력을 받음. 막히면 낮은 모델·다른 무료 AI로 자동 교체 |
| 판단 B | Claude Haiku | 한도에 걸리지 않는 고정 판단자. 무료 AI가 모두 막혀도 토론이 유지됨 (질문당 1센트 안팎) |

허브와 같은 AI를 판단자로 고르면 허브와 **다른 모델**(예: Sonnet 허브 → Haiku 판단자)을 기본으로 씁니다.

### 비용 표시
Claude 응답의 실제 토큰 사용량과 웹 검색 횟수로 질문마다 비용을 계산해 답변 아래에 표시하고, 사이드바에 **이번 달 누적액 / 월 예산**(`CLAUDE_MONTHLY_BUDGET`, 기본 150달러)을 보여줍니다. 대화 기록으로 계산한 추정치이며, 정확한 금액은 console.anthropic.com에서 확인하세요.

### Claude 생각 수준
Claude는 단계마다 생각하는 정도(effort)를 다르게 씁니다. 되묻기 `low`, 질문 정리 `medium`, 최종 판정 `high`(품질 우선)이며, `CLAUDE_EFFORT_CLARIFY`, `CLAUDE_EFFORT_BRIEF`, `CLAUDE_EFFORT_VERDICT`로 바꿀 수 있습니다. 낮을수록 빠르고 저렴합니다. 답이 최대 길이에 닿아 잘리면 화면에 알립니다.

### 사용량 한도에 걸리면
무료 한도는 모델마다 따로 계산되므로, 판단자가 한도에 걸리면 **상호 검토가 유지되는 순서로** 자동 교체하고 화면에 알립니다.

1. 같은 AI의 낮은 모델 (예: Gemini flash → flash-lite, Groq gpt-oss-120b → gpt-oss-20b)
2. 다른 AI (Mistral, OpenRouter 등)
3. 허브 AI의 다른 모델 (예: 허브가 Sonnet이면 Haiku)
4. 허브가 같은 모델로 판단자를 겸함 (최후의 수단)

- 한도에 걸린 **모델만** 자동 제외되며, 제외 기록은 앱 서버에 남아 새로고침해도 유지됩니다. 해제되면 다음 질문부터 원래 모델로 돌아갑니다.
- Gemini 일일 한도는 초기화 시각(태평양 시간 자정)까지, 분당 한도는 API가 알려준 대기 시간만큼만 제외합니다.
- 판단자는 오래 기다려야 하는 재시도 대신 바로 낮은 모델로 교체해 시간을 아낍니다. **판단 시간 제한**은 재시도·교체를 포함한 전체 상한입니다.
- 낮은 모델 목록은 `GEMINI_FALLBACK`, `GROQ_FALLBACK` 등으로 바꿀 수 있습니다(`secrets.toml.example` 참고).

대화는 질문마다 자동 저장되며, 사이드바 **📚 대화 기록**에서 검색·열기·이어가기·삭제할 수 있습니다. `GITHUB_TOKEN`과 `DATA_REPO`를 넣으면 비공개 GitHub 저장소에 영구 보관합니다(이미지 원본은 저장하지 않음).

후속 질문은 직전 **최종 판정**을 출발점으로 이어지며, 결론이 바뀌면 무엇이 왜 바뀌었는지 밝힙니다.
대화 중 첨부한 PDF·TXT·MD·이미지는 같은 대화 안에서 계속 참고됩니다.

### 질문을 잘못 보냈을 때
토론 중에 오타나 잘못된 질문을 발견하면 진행판 위의 **⏹ 중단**을 누르거나, **고친 질문을 입력창에 바로 보내세요.** 진행 중인 AI 호출이 1초 안에 취소되고(끝나지 않은 호출은 비용도 덜 듦), 중단한 질문은 기록에 저장되지 않습니다. 화면 오른쪽 위 Streamlit의 Stop도 호출을 멈추지만 진행판이 멈춘 채로 남습니다.

## 지원 AI
| AI | Secrets 키 | 비고 |
|---|---|---|
| Claude | `ANTHROPIC_API_KEY` | 허브 권장 (Team 요금제 API 크레딧) |
| Gemini | `GEMINI_API_KEY` | 무료 등급 |
| Groq | `GROQ_API_KEY` | 무료 등급, 학습에 사용 안 함 |
| Mistral | `MISTRAL_API_KEY` | 무료 Experiment 플랜 |
| OpenRouter | `OPENROUTER_API_KEY` | `:free` 모델만 표시 |

키가 있는 AI만 화면에 나타나고, 모델 목록은 각 API에서 자동으로 불러옵니다.
설정 예시는 `secrets.toml.example`을 참고하세요.

> ⚠️ API 키는 절대 커밋하지 마세요. `APP_PASSWORD`는 **필수**입니다. 설정하지 않으면 앱이 열리지 않으며, 5번 연속 틀리면 1분간 잠깁니다.
> 일부 무료 API는 입력 내용을 학습에 사용할 수 있으니 개인정보가 담긴 파일은 올리지 마세요.

## 파일 구조
| 파일 | 내용 |
|---|---|
| `app.py` | Streamlit 화면 (사이드바 설정, 진행판, 되묻기 양식, 결과 표시) |
| `majority/settings.py` | 설정값, Secrets 읽기, AI 공급자 등록부 |
| `majority/models.py` | 모델 목록 조회, 한도 초과 시 낮은 모델, 판단자 기본 모델, 모델 이름 표시 |
| `majority/llm.py` | 공급자별 AI 호출, 재시도·한도 판별, Claude 사용량·비용 |
| `majority/prompts.py` | 입력 정리, 단계별 프롬프트, 되묻기 질문 해석 |
| `majority/pipeline.py` | 토론 진행(정리 → 1차 판단 → 반론 → 판정), 자동 제외 |
| `majority/store.py` | 대화 기록 저장소 (GitHub 또는 로컬 `data/`) |
| `tests/` | 시험 (실제 AI API는 부르지 않음) |

> Secrets의 기본 모델 등(`GEMINI_MODEL` 등)을 바꾼 뒤에는 Streamlit Cloud에서 **Reboot app**을 해야 반영됩니다. 설정은 앱이 시작할 때 한 번 읽습니다.

## 시험
AI API를 실제로 부르지 않고 가짜 응답으로 로직과 화면 흐름을 확인합니다. PR을 올리면 GitHub Actions가 자동으로 실행합니다.

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q tests
```
